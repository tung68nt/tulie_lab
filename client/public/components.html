30. Quy tắc thiết kế (Do / Don't)

Màu sắc & Visual

✓ Nên
• Dùng semantic color vars (--primary, --muted, --destructive)
• Background: bg-background/bg-card/bg-muted
• Shadows: 5 cấp (sm → xl)
• Glow effects chỉ cho section background
✘ Không
• Hardcode màu (#3b82f6 thay vì var(--info))
• Gradient trên button/badge
• Box-shadow custom inline
• Neon glow / text-shadow trên text thường

Typography & Text

✓ Nên
• Font Inter, weight 400-800
• text-foreground / text-muted-foreground
• line-height relaxed cho body
• Code font: JetBrains Mono
✘ Không
• text-transform: uppercase
• letter-spacing (tracking)
• Font size tuỳ tiện (adhoc px values)
• Emoji trong button text

Components

✓ Nên
• Button: 6 variants, active scale(0.97)
• Card: border + rounded-xl, padding 20px
• Badge: rounded-full, 3 sizes
• Input focus: ring 2px var(--ring)
✘ Không
• Scale hover lớn (> 1.02)
• Custom border-radius khác system
• Inline styles cho component thường
• Animation bounce/pulse trên text/button

Layout & Spacing

✓ Nên
• Container max-width 1200px centered
• Section py-20 md:py-28
• Grid system: 2/3/4 columns
• Gap scale: 2/3/4/6/8 (Tailwind)
✘ Không
• Arbitrary values (gap-[13px])
• Padding/margin không đều
• Full-bleed content không container
• Z-index vượt quá 100 (trừ modal/toast)
Tóm tắt: Hệ thống theo shadcn/ui neutral preset. Mọi component phải dùng design token, không hardcode giá trị. Dark mode tự động qua CSS variables. Layout responsive mobile-first. Transition duration 150-300ms, ease-in-out.
