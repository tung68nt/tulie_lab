# Rà soát toàn bộ UI/UX - Tuân thủ Vercel Design Guideline

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Kiểm tra toàn bộ hệ thống giao diện có tuân thủ UI guideline: tone đen trắng, style hiện đại, clean theo phong cách Vercel/Geist. Rà soát các trang/chức năng còn thiếu hoặc chưa hoạt động. Sau khi đánh giá tổng thể mới xem xét upgrade tech stack.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Tất cả font-weight không vượt quá 700 (bold)
- [ ] #2 Không có text uppercase trên toàn hệ thống
- [ ] #3 Không có letter-spacing trên toàn hệ thống
- [ ] #4 Tone màu đen trắng nhất quán theo Vercel/Geist design
- [ ] #5 Tất cả các trang đều hoạt động đúng chức năng
- [ ] #6 Không có trang/chức năng bị thiếu hoặc broken
- [ ] #7 Đánh giá tổng thể hoàn tất, đưa ra khuyến nghị upgrade tech stack
- [ ] #8 Push git main thành công cả backend và frontend, triển khai lên Cloud Run
<!-- AC:END -->
